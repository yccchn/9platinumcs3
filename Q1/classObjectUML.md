# SG4 - Understanding Classes and Objects
## Class Name: Missing Your Ex
## Class Description
This class represents a person who still misses their former partner and the different actions they do because they miss their ex.
## Properties
| Property | Data Type | Description |
| exName | string | Name of the ex |
| endedWhen | string | When the relationship ended |
| reasonForMissing | string | Why the person misses their ex |
| lastContact | string | When the person last contacted their ex |

## Methods
| Method | Description |
| reachOutOnHoliday(holiday: string) | Reaches out to the ex during a holiday |
| messageLateAtNight() | Messages the ex late at night |
| callOnBirthday() | Calls the ex on their birthday |
| dreamAboutEx() | Dreams about the ex |

## Design Explanation
### Why did you choose this class?
I chose this class because missing an ex is a relatable real-world situation, and it can be represented through different information and actions.
### Which property is the most important? Why?
The most imoirtant property is reasonForMissing because it explains why the person still missing their ex. Moreover, without it, the clss itself would not exist.
### Which method is the most useful? Why?
The most useful methos is reachOutOnHolday(holiday: string) because the parameter allows the method to work with different holidays, such as Christmas and New Years.
